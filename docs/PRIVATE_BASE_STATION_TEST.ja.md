# 146 MHz帯の基地局試験受信・IQ取得（v0.3.2-alpha）

**京急・京成・北総の音声復号は未確認です。** ユーザーから「142 MHz帯は移動局側」と訂正を受け、新たに提供されたJR-D Receiverの基地局設定写真の16波へ置き換えました。旧142 MHz帯の移動局16波は、選択一覧・直接入力・RTL-TCP設定・Rust/JNIの受信対象から削除しています。

新しい写真では「京急・京成基地局」と下向き矢印、データ波・音声波の種別が表示されています。写真の周波数設定を実装したもので、音声受信成功や私鉄専用のフレーム・コーデックを実装済みという意味ではありません。K1/K2/K3の路線・区間ごとの運用は別途確認が必要です。

## 更新と選局

1. 現在のアプリと同じ種類（通常版 / 別インストール版）のv0.3.2-alphaへ更新します。
2. 受信を停止し、「受信対象・周波数を選択」→「京急・京成・北総 基地局 · 146 MHz帯（試験）」を選びます。
3. 対象の音声波を選びます。例はK1-1音声の146.48125 MHzです。K1データの146.49375 MHzとは別の設定です。
4. 146 MHz帯を受けられるアンテナを用意し、画面の周波数を確認して「受信開始」を押します。
5. IQ数、同期フレーム、有効音声、PCM、実際の音声を確認します。IQや同期だけが増えても音声復号成功とはしません。

旧版で142 MHz帯の設定を保存していた場合、同じチャンネルの基地局側（+4 MHz）へ自動的に引き継ぎ、その値を保存し直します。例: K1-1は146.48125 MHzになります。JRの保存設定と新規導入時の旅客一斉352.62500 MHzは維持します。壊れた値は旅客一斉へ戻します。旧142 MHz帯を直接入力して選局することはできません。

146 MHz設定の「前の設定」「次の設定」は写真の一覧順です。周波数差は一定ではありません。JRモードの±6.25 kHz操作は従来どおりです。

内部では既存JR用のπ/4-DQPSK・40 msフレーム・Modified RL-CELPとSlottedデータ形式を試します。実際の私鉄信号との互換性は未確認です。[コーデック等の調査記録](KEIKYU_RESEARCH.ja.md) を参照してください。

## 同期しない・音声が出ない場合のIQ取得

1. 受信中に「調査用 IQ を5秒取得」を押します。
2. 保存完了表示まで待ちます。取得は5秒相当（1,200,000複素サンプル、2,400,000 byte）で終了します。
3. 「IQ をダウンロードに保存（ZIP）」を押し、保存完了を待ちます。Galaxyでは「ダウンロード/JRDroid」に保存します。
4. ChatGPTで先にCodexへ切り替え、ファイル選択から保存したZIPを添付します。受信した設定、放送があったか、同期・音声・PCM数も添えてください。
5. 従来の「保存した IQ を共有」も利用できます。Codexへの切り替え時に添付が消える場合は上のZIP保存を使ってください。[詳細手順](IQ_EXPORT.ja.md) を参照してください。

データは未復調のunsigned 8-bit interleaved I/Qです。最初の行がUTF-8 JSONメタデータ、改行以降がraw IQです。周波数、要求レート・ゲイン・ppm、端末での取得開始時刻、実際のbyte数、取得完了フラグを含みます。設定値を機器から読み戻したものではありません。5秒相当のデータが揃ってもドライバー側の欠落ゼロを保証しません。

停止前に5秒分が揃わなかった場合は `complete:false` と実際のbyte数を保存し、画面にも途中取得と表示します。開始前に停止した場合は中止扱いです。ファイル出力は専用ワーカーで行い、保存失敗を理由に受信を停止させません。メモリ上の取得サイズと保存待ちキューに上限を設けています。

最新の取得ファイルはアプリの非公開キャッシュに保持します。共有時には別の不変コピーを作り、前の共有URIで将来の取得データが読まれないようにしています。共有コピーは最大4件の一時キャッシュです。キャッシュ削除や古いコピーの整理で共有URIが利用できなくなる場合があります。必要なデータは共有先で保存してください。取得ファイルは `.gitignore` に指定し、GitHubへのソース公開物には含めません。

ホストではメタデータと長さを次のように確認できます。

```bash
python3 scripts/inspect-capture.py /path/to/capture.jrd-iq
python3 scripts/inspect-capture.py /path/to/JRDroid-IQ-example.zip
```

このスクリプトはファイル形式の確認で、私鉄の音声を復号するものではありません。

## 検証範囲

画像の16設定がJava・RTL-TCP・JNI・Rustへ渡ること、旧移動局16設定を拒否すること、保存設定の移行をホスト試験で確認します。JR合成信号からPCMが出ても、京急の実電波との互換性の証明にはしません。実際の実行結果は [検証記録](VALIDATION.ja.md) を参照してください。

5秒相当のIQファイル形式はv0.3.0-alphaと共通です。ユーザー提供の旧版IQファイルは正常に読み取り可能でしたが、今回の基地局側での音声受信確認とは別です。Android実機での新しい選局・保存設定の移行・基地局信号の復号は未確認です。
