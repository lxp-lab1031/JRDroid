## セットアップ中に修正・回避した問題

- 最新の command-line tools は新 Android CLI に切り替わり、標準ホームの書き込みで停止しました。旧 sdkmanager もこのプロキシ環境ではマニフェストの取得に失敗したため、Google の公式 HTTPS マニフェストのチェックサムに照合した固定 SDK/NDK アーカイブを展開する方法にしました。TLS・チェックサム検証は無効化していません。
- JDKの開発部分が未導入だったため、既存 OpenJDK21 runtime と同版の Debian 公式 JDK package を SHA-256 確認後に展開しました。
- Android/Gradleの設定・キャッシュ・デバッグ署名の保存先を `/workspace/toolchains` に設定し、ビルドを成功させました。AGP の任意の analytics 処理には標準ホームの読み取り専用に関する警告が残ります。
- 付属 adb 37 は標準の `/home/agent/.android` 作成を試み、この環境の読み取り専用マウントで起動できませんでした。ディレクトリ書き込み権限の追加だけではマウント制限を解消できません。**クラウドからの adb 接続は使えません**。これは APK ビルドとホスト検証には不要で、端末への導入は APK の手動転送、または開発用PCの adb を使います。
- BOOTH の比較対象ページは HTTP403 のため調査できませんでした。配布物・ライセンスを取得したとはしていません。
