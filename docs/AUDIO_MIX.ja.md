# 他アプリとの音声ミックス

JRDroidの受信音声と、YouTube・TikTok・音楽再生アプリなどのメディア音声を同時に聴くための構成です。v0.2.3-alphaで導入し、現行v0.3.2-alphaへ継承しています。実機報告の対象となる版は末尾に区別して記録しています。

## 変更

- `AUDIOFOCUS_GAIN` の要求を削除しました。JRDroidの開始で他アプリに音声フォーカスの喪失を通知する処理を行いません。
- フォーカス喪失通知を受けてJRDroidの受信を停止する処理も削除しました。
- `USAGE_MEDIA` / `CONTENT_TYPE_SPEECH` のAudioTrackを使用し、Androidのメディア出力でミックスします。
- 内蔵スピーカーへの優先デバイス指定を外し、Androidで選んだスピーカー・Bluetooth・有線機器などのメディア出力に従います。
- v0.2.2-alphaで導入された受信セッションの分離・非同期停止・音声出力の所有スレッドは変更していません。今回の作業は停止警告の再調査ではなく、音声フォーカスと出力先の変更です。

## 手順

1. 今のアプリと同じ種類（通常版 / 別インストール版）の現行版v0.3.2-alphaへ更新します。
2. JRDroidで受信を開始します。
3. YouTube・TikTok・音楽アプリを開き、相手側で再生を開始します。JRDroidは受信サービスとして継続する設計です。
4. 実際の列車無線の放送中に、両方の音声が同じ出力先から聞こえるか確認します。
5. 相手アプリの一時停止・再開、JRDroidの停止・選局・受信再開、Bluetoothなどの出力先変更も確認します。

YouTubeやTikTokには、前面から離れた際に再生を止める動作があるため、JRDroidを開始してから相手アプリへ戻って再生する順序を推奨します。相手アプリ自身のバックグラウンド再生条件を変更する機能ではありません。

音量は端末のメディア音量に従います。JRDroidだけの独立した音量調整や、他アプリの音量を操作する機能は今回追加していません。

## 検証範囲

停止修正版 `stop-fix-20261103` のコミット `24872376a0d7cc019d61e1a5ec256abb754d7adb` を基にしています。受信・DSP・音声合成は変更していません。既存の受信テストと停止・再開のホスト試験を実行し、通常版・別インストール版をビルドします。

ユーザーからTikTokとの音声ミックスと、Bluetoothイヤホンからの出力を確認したとの報告を受けました。

2026-11-04に、**142 MHz帯の受信設定があった旧版で、YouTubeアプリとのミックス音声がBluetoothイヤホンから出ることを確認した**との追加報告がありました。同時に、**現行版では未確認**と明示されています。

| 対象 | YouTubeとのミックス＋Bluetoothイヤホン出力 |
|---|---|
| 142 MHz帯対応の旧版 | ユーザーの実機報告で確認済み |
| 現行v0.3.2-alpha | 未確認 |

配布履歴では142 MHz帯対応版はv0.3.0-alphaに相当しますが、今回APKの版番号そのものは提示されていません。「142 MHz帯対応の旧版」というユーザーの説明を根拠とし、142 MHz帯の実放送の受信・復号成功を追加で確認したものとは扱いません。

音楽アプリとの同時再生、再生中の出力先切替、電話の割り込みは未確認です。これらの実機報告はユーザーによるもので、クラウドで同時再生を再現した試験ではありません。受信・音声の実装を継承していても、旧版の確認を現行版の実機成功として扱いません。
