# D タイプの周波数選択（v0.2.0-alpha）

旅客一斉の固定受信から、352 MHz 帯の22波を1波ずつ選局できるようにしました。

## 操作

1. 受信中なら「停止」を押し、停止処理が終わるまで待ちます。
2. 「周波数・D チャンネルを選択」で一覧から選ぶか、「MHz を直接入力」で値を設定します。メイン画面の ±6.25 kHz ボタンでも隣の周波数へ進めます。
3. 大きく表示された MHz を確認して「受信開始」を押します。
4. 選局した周波数は画面・受信通知・ドライバー・Rust の受信パイプラインに反映します。選択はアプリ終了後も保存します。

初期周波数は旅客一斉の **352.62500 MHz**。許容範囲は **352.53750〜352.66875 MHz / 6.25 kHz 刻み**で、範囲外や刻みに合わない値はエラーとして受け付けません。小数点以下5桁を表示して 352.55625 MHz などを丸めずに扱います。

受信中とドライバー起動中は選局できません。停止と再開で新しい受信パイプラインを作るため、前の波の同期・音声状態を次の波へ引き継ぎません。選局直後の画面に前の周波数のカウンターを表示しないようにしています。

## 受信処理と検証範囲

要求サンプルレート240 kS/s、ゲイン40.2 dB、補正0 ppmは従来と同じです。ハードウェアの中心周波数と Rust の中心周波数・対象周波数を同じ選択値に設定して1波を復調します。旅客一斉は上流の `Common`、その他の波は `Slotted` 形式を使います。上流 DSP・音声合成ライブラリは変更していません。

チャンネル一覧と上流の一致、入力検証、全22波の RTL-TCP コマンド、JNI への周波数引き渡し、全22波の合成信号からの PCM 出力をホストで検証します。Android UIでの選局・設定保存・通知・実際の別周波数受信は対象端末で確認が必要です。旧版の352.62500 MHzの実機成功を、新版の全22波の実機成功としては扱っていません。

## 更新

通常版は `jp.jrdroid`、別インストール版は `jp.jrdroid.standalone` を継続使用し、versionCodeを1から2へ上げています。同じ種類の旧版 APK と同じデバッグ署名を使って更新できるようにビルドします。通常版と別インストール版の設定は別々に保存されます。
